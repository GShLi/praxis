# 结构整理与后续开发

2026-11-03，依据 `AGENTS.md` 完成现有源码的结构整理和逐文件审查。原协议、公共 API、持久化格式保持兼容；生命周期修复单独增加回归验证。

## 已整理

- UI：设置分类、会话组件、身份/导航/订阅 hooks 与 Web/本地客户端适配器分离。CSS 按语义模块拆分并保留原层叠顺序，生产 CSS 哈希仍为 `BeAM_z1E`。
- Runtime：调度、用户问题、turn 生命周期、step、提示词、响应校验和工具批次分离。Chat 的事务接纳、上下文与生成分离。
- 存储与工具：SQLite 仓储共用事务所有者；文件路径、内容观察、原子发布与搜索分开；插件委托和错误结果处理独立。
- Host/CLI/桌面/Server：入口装配与 RPC/HTTP 分组分离；资源归实例或操作所有。CLI 退出移除监听，Host 握手失败回收子进程，重复关闭共享 Promise，桌面/服务端部分初始化失败释放已取得资源。
- 包边界：所有跨包源码引用使用 `@praxis/*` 公开导出，依赖写入包清单；无循环依赖（含类型依赖），内部不反向导入自己的入口。
- 网络：模型请求序列化、HTTP 请求、SSE 读取、结果累计各自独立；DNS 与 IP 策略从 HTTP 流生命周期提取。

## 持续检查与例外

`pnpm structure` 已接入 `pnpm check`。检查源码/CSS/C 文件规模、函数规模、薄 index、显式导出、依赖声明、公开子路径、自身入口回导、跨包相对路径和文件依赖环。它不代替行为、安全与平台验收。

[具体例外清单](structure-exceptions.json) 是逐项复核记录：每项标注精确文件/符号、当前最大行数、保留完整职责的原因及验证范围。原生资源生命周期、同一事务/压缩算法、连续 JSX、集中注册表和完整测试场景允许保留；这不是给整个目录的无限豁免。后续任何超限增长都会触发检查，不能通过换文件名或修改阈值规避评审。

生产 TS/TSX/CSS 文件均小于 300 行；5 个超过 300 行的测试文件仍小于 500 行，并按同一能力保留用例和 fixture。测试中的双重类型转换仅用于有意不完整的 PostgreSQL/HTTP 假适配器，未用来掩盖生产拆分的类型问题。

验证：结构检查、TypeScript（包括 UI fixture）、63 项行为测试、四入口构建、CLI doctor 通过。新增测试验证真实 Host 并发关闭、错误握手回收、交互 payload 校验和结构门禁。浏览器样例成功构建，但本轮浏览器访问主机不可用，Firefox 访问被工具拒绝，未重复视觉点击验收；此前 UI 样例验证记录不等同本轮复查。尚未声称 Electron 安装包和三个操作系统的真实验收通过。
