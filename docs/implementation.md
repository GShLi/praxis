## 工程与协议

### MCP 文本资源与资源模板

2026-11-03：增加 `mcp_list_resources` 和 `mcp_read_resource`，只有配置明确开启 resources 时注册。列表先完整获取有界目录，再返回本轮作用域的资源/模板引用与分页引用；远端游标不传给模型。引用绑定用户、客户端、服务器、配置和目录版本，刷新失败或目录变化会使旧引用失效，不跨会话或重启恢复。

读取前展示实际远端 URI 与模板参数并取得单次审批，重新核验目录，再记录分发意图。模板只接受已发现变量的字符串值；不展开环境变量、本机路径或 Shell。资源中的 `file://`、HTTPS 等 URI 都只作为 `resources/read` 参数发往原 MCP 端点，Host 不直接访问这些地址。

文本及来源 URI、内容 hash、获取时间和产物引用随结果保存，历史查看使用保存快照。二进制不进入文本上下文，纯二进制资源明确失败；混合内容保留不支持标记。引用仅保存目录条目索引，不为每个引用复制整份目录。大小、页数、条目数、超时和取消沿用有界操作。

6 项新增真实 HTTP 测试通过，覆盖新旧协议、分页/游标隐藏、模板变量、跨会话引用、目录变化、拒绝、取消、二进制/超限，以及本机文件不被读取。累计 85 项核心测试、结构检查、类型检查、四入口构建通过。本轮再次检查浏览器，访问主机仍不可用，未进行新的 UI 点击验收。stdio、Bearer/OAuth、Prompts、MRTR 和三平台命令沙箱仍未完成。

### MCP 远程工具执行

2026-11-03：接入可选的 turn 级工具扩展，Agent Loop 不引用具体 MCP 服务。支持用户先检查再明确启用无认证 Streamable HTTP 服务；桌面设置提供启用入口，CLI 提供 `mcp list/import/test/enable/disable`。CLI 的 enable 在同一 Host 内先执行检查，成功后提交启用，不因 test 自动启用。

`mcp_discover_tools` 只读取已启用固定端点的目录，不向远端发送查询文本。定义在下一 step 激活，同一工具批次中猜测名称会拒绝。每个业务调用通过真实 ApprovalGate，核对配置、权限与实际远端目录后消费一次票据，记录 dispatch 后才发送请求。保留原始参数 Schema，由官方 SDK 生成新版参数镜像头；旧版初始化和调用也已验证。已知厂商 Key/Praxis Key 出现在参数时拒绝发送。目录按会话产物保存，事件保留引用，模型请求与工具集快照可以重建当时可见定义。

编辑/停用立即取消该服务器当前操作；Host 关闭回收请求。远端业务失败、Schema 错误、断流及分发后取消均保守保留未知效果，不自动重放。结构化结果支持完整 JSON 值，包括 `false`。崩溃恢复补记未终结操作为 interrupted，分发后的效果为 unknown，不恢复网络会话或审批。

本机 79 项核心测试、结构检查、TypeScript 与四入口构建通过。新增 11 项 MCP 测试使用真实本机 HTTP、官方 SDK、Agent/ToolExecutor、ApprovalGate 和 SQLite，覆盖新旧协议、下一步生效、参数头、版本变化、审批撤销、停用取消、断流不重试和重启恢复。模型仍为确定性 fixture；本轮未做桌面实际点击或外部生产服务验收。

### 插件运行时与静态检查补全

2026-11-03：可信插件的 `contributeContext` 在每个本地 turn 开始时执行一次，接收该轮取消信号，生成带插件 ID、版本、包摘要的数据包络；同一轮各 step 重用该快照，请求快照保存实际内容，不伪造原始对话。单项限制 8 KiB、合计 32 KiB，单项执行限制 2 秒。上下文贡献失败会终止本轮，不静默忽略。

`onTurnFinished` 在终态及 checkpoint 提交后调用，所有结束钩子共享 2 秒预算；取消的任务同样执行有界清理钩子。迟到返回不进入运行时，异常只记录稳定错误。插件仍是用户信任的同进程代码，取消信号不是隔离恶意代码或强制终止同步死循环的沙箱。

启用 TypeScript `noUnusedLocals` / `noUnusedParameters`，清除拆分后未使用的 RPC 解构和 UI 参数，同时保留身份检查副作用。结构检查、类型检查、67 项核心测试和全部入口构建通过；新增 4 项测试覆盖固定上下文、提交顺序、超时取消、大小和敏感错误边界。插件 Provider 路由、用户命令等尚未接入。
