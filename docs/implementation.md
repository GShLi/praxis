# Praxis 实现记录

设计目标见 [开发计划](superpowers/plans/2026-11-03-praxis-development-plan.md)。此文件只记录已有实现及验证，不用设计文档的存在代替功能完成。

## 工程与协议

2026-11-03：建立 pnpm workspace、TypeScript strict、版本锁、共享 Zod 合同、JSON 行 RPC、独立 Host 和 CLI doctor。Host 支持主版本校验、实例 nonce 回传、心跳失效退出、管道断开退出及显式关闭；帧和发送缓冲有 8 MiB 上限，控制请求不等待慢业务请求完成。

本机验证：类型检查、3 个协议/子进程测试、CLI doctor 通过。依赖网络 DNS 被当前执行环境限制，使用本机 npm 缓存中的完整性校验包进行离线安装，并由 package-lock 导入 pnpm-lock；未完成联网的干净 pnpm 安装验证。验证时使用 `pnpm_config_verify_deps_before_run=false pnpm check`，避免 pnpm 对非 pnpm 安装目录自动联网重装。常规开发环境仍按 README 使用冻结锁文件安装。

测试入口使用 `node --import tsx`，避免 tsx CLI 创建不必要的本地 IPC 监听器。CI 配置覆盖 Linux、macOS、Windows 的 Node 22.15/24；配置尚未在远端运行，不代表已通过三平台验证。

## 执行核心与上下文

2026-11-03：SQLite WAL 保存 Session、输入去重、原始消息/工具结果、请求快照、版本化摘要、产物与 checkpoint。运行时实现多轮、queue/steer、安全边界、取消、工具预算、用户问题和中断恢复；工具包括版本化文件读写/补丁、目录/glob/字面量搜索、计划和产物读取。DeepSeek 适配收集完整 SSE/工具批次后才返回；流中断不重试工具。命令后端尚未接入，调用会明确拒绝。

本机类型检查及 14 项测试通过：真实 HTML 创建/修改、重复请求、陈旧版本/部分读取/补丁失败、越界链接、Chat 工具隔离、取消/挂起、未知工具恢复、事务事件发布、连续压缩与摘要失败、流式 UTF-8/参数重组和中断。测试模型通过依赖注入，仅用于测试；尚未使用真实模型 Key。搜索正则、子目录指令发现、跨进程工作区锁、原生路径竞态防护、平台执行、生产客户端接入仍需补齐。

## Web 与桌面客户端

2026-11-03：React/Vite 共享界面连接 Web HTTP/SSE 或 Electron 私有 preload RPC；支持身份登录、统一模型设置、历史、多轮流式回答、停止、工作区选择、问题回答和文件变更快照。Web 会话刷新使用同源互斥与会话绑定 CSRF，兼容多标签页；Electron renderer 禁止 Node、远程连接和任意 IPC。生产 Web 文件由同一服务端提供。

本机 19 项测试、TypeScript 与 Web/Host/CLI/桌面构建通过。通过 Chrome 打开独立开发样例，检查了对话代码块、Chat/Agent 切换和工具记录；样例明确标注无模型调用，不能替代真实登录/服务端/模型端到端验收。Electron 安装包、三平台沙箱、插件/MCP 与发布仍未完成。

## 工作区和文件边界

原生锁已增加祖先共享锁/目标独占锁，真实子进程测试覆盖同目录、嵌套目录、符号链接别名排他及兄弟目录并行；桌面与 CLI 使用同一用户级协调目录，profile 数据目录不再影响占用一致性。文件工具拒绝受保护应用数据、链接别名、硬链接和 Windows 设备/ADS 歧义路径，并在异步准备后重新检查写权限。SQLite 文件以 0600 创建。22 项本机测试通过。

当前执行环境运行 `/usr/bin/sandbox-exec` 返回 `sandbox_apply: Operation not permitted`，无法完成 Seatbelt 内核验收。没有以普通进程冒充设计中的隔离支持。

已实现版本化配置、受限 JSON Schema 校验、插件清单/文件摘要检查、显式信任安装、默认禁用和原子激活。可信插件工具可以通过 Host 委托内置文件工具，保留权限和执行记录；ChatBot 不注册插件工具。插件管理已接入 CLI 和桌面设置。Provider、命令及上下文贡献扩展的注册合同已建立，完整运行时接入仍待完成。

MCP 已实现服务器配置、分页目录快照、工具稳定命名、下一步生效的工具选择、参数镜像 Header、资源作用域和结果规范化。配置保存后保持禁用，传输和审批未就绪前明确拒绝连接。官方 v2.3.1 Client/Core 已通过浏览器从 npm 下载，与 npm 元数据的 SHA512 完整性匹配后导入离线缓存并安装；此前的 SDK 缺包阻碍已解除。没有把配置页和目录单测视为 MCP 端到端完成。
