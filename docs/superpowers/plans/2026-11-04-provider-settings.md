# 供应商设置调整

用户已要求修复审查问题，添加/编辑改用弹窗，并采用本机 10100 页面中的列表与详情布局。

- 共享 UI 保留设置导航，主区使用可搜索的供应商列表与详情，详情分概览和模型。添加、编辑和删除确认均在原生 dialog 中，提供键盘焦点约束、未保存保护、保存期间操作锁定和失败重试。
- auth 的供应商记录继续拥有唯一加密 Key。JSON 配置新增可选 models，每个模型包含稳定 ID、模型名称、容量和启用状态。旧记录按 default 模型读取，无须改写用户数据库。defaultModelId 指向基础模型，根 model/capacity 保留其兼容别名，服务端验证一致性。旧客户端只修改基础模型时保留其他模型。
- model-core 提供模型配置和选择标识规则；原供应商 ID 仍选择 defaultModelId（旧记录为 default），其余使用 providerId:modelEntryId。UI、桌面和 CLI 继续使用已有 providerId 入口，鉴权和凭据解密始终以供应商 ID 为边界。
- 弹窗状态 Hook 拥有草稿和异步请求代次；视图拆成连接字段、模型选择及容量字段。更新 Key 只使模型发现结果失效，不删除已选模型。不同地址或适配器仍需新 Key。
- 列表获取结果只声明目录访问成功，不声明生成验证成功。默认模型属于当前客户端偏好，页面明确标注范围。
- 验证：schema/选择规则回归、独立 PostgreSQL 兼容与密钥测试、完整 check/build、开发样例浏览器交互与窄屏检查。真实配置与会话不用于破坏性测试。
